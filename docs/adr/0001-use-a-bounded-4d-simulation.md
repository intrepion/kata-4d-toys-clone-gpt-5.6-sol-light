# Use a bounded 4D simulation

The experience will use genuine four-dimensional geometry, transforms, and slice intersections, paired with a deliberately bounded physics vocabulary for supported convex shapes and constraints. This preserves behavior players can test—such as disappearance across the slice, four-dimensional rotation, falling, rolling, stacking, and recovery of off-slice toys—without misrepresenting scripted 3D morphs as 4D or committing the project to a fully general research-scale 4D rigid-body engine.
